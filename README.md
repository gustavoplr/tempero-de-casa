# Tempero de Casa
Blog de gastronomia para a AOP2, feito com HTML, CSS e JavaScript básico.

Abra index.html para navegar. As cinco páginas compartilham a navegação; as três imagens da Home levam às receitas. Textos e ilustrações SVG criados para este projeto. O formulário apenas prepara texto localmente.

## GitHub Pages
Crie um repositório e envie as cinco páginas, style.css, contato.js e a pasta assets. Em Settings > Pages, selecione Deploy from a branch, main e /(root). Aguarde o endereço público aparecer.

Para a entrega, use o link principal do repositório e o endereço do GitHub Pages. Personalize e revise o projeto antes de enviar.
